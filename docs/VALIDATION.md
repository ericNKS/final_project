# Validação histórica CPU

Os resultados CPU preservados em `resultados/runs` são registros históricos. Seus próprios manifestos, métricas e hashes são a evidência pertinente; não constituem a execução GPU de referência atual. Não há equivalência numérica presumida entre backends.

Veja [GPU_VALIDATION.md](GPU_VALIDATION.md) para as referências atuais e [METHODOLOGY.md](METHODOLOGY.md) para critérios e limites da avaliação.
